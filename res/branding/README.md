# 启动图、平台图标与分享素材

`launcher-original.png` 是已选启动图的原稿。正式 1024 × 1536 JPG 在游戏工程的 `assets/resources/launcher.jpg`，随微信主包导出。进度条由启动场景单独绘制，适配不同屏幕比例。

`app_icon_144.png` 是供微信后台使用的 144 × 144 图标，`icon_original.png` 是新绘人物与城门合成的高清图标源。平台图标与游戏运行美术分别管理。

`share/` 保存微信三点菜单分享图的高清原稿、500×400 发布图和制作说明。发布图同时复制到游戏工程的 `build-templates/wxgame/share/`，随主包导出，不参与游戏图集或分包。
