# 村民四向朝向与步态

男村民、女村民、中性孩子、中性老人：四个真实方向，每向八帧行走及独立双脚落地站姿，共144张512×512透明母片。婴儿另有四帧躺卧呼吸。成年男女劳动、老人休息分别在source/rendered2d/characters对应目录，已接入正式二维资源合同。

镜头和灯光固定，整套骨骼及脚踝/膝盖控制一起转向，不镜像、不扭头追镜头。四向采用同一母画布与公共足点，禁止逐帧按轮廓居中。每个身份保留独立绑定和脚底验证报告。

八个行走姿态包含左右脚半周期交替的落地、承重、摆动；停止用独立站姿。实际游戏以真实路程除以显示步幅推进相位，短途重启不重置，倍速不重复相乘。老人以各自髋关节为中心布置脚轨迹，在握杖高度不变的前提下扩大步幅，避免过快碎步；未改移动速度或年龄规则。

[素材对照页](../review.html) 展示四向循环；预览成人/孩子16fps、老人12fps、婴儿2fps，属于素材检查节奏，实际运行频率由步幅和移动距离决定。各目录manifest保存当前图片哈希。早期独立小场景四帧验收只作为历史，正式游戏结果以技术文档32最后记录为准。
