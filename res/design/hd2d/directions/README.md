# 村民四向朝向检查

用户指出上下左右行走时，脸的朝向不自然。本目录专门检查脸、肩膀、躯干、脚和动作方向的一致性。

## 当前素材

男村民、女村民、中性孩子、中性老人均保存四向各四帧，共 64 张 512×512 透明母片；婴儿另有四帧躺卧呼吸。它们是各身份模型和骨骼的真实 Blender 离线渲染，源文件按身份保存在 `res/source/rendered2d/characters/`，不是把正面图镜像成侧面。

| 目录 | 内容 | 播放节奏 |
| --- | --- | --- |
| `male/` | 蓝衣短发男村民，四向行走 | 每秒 6 帧 |
| `female/` | 橘衣束发女村民，四向行走 | 每秒 6 帧 |
| `child/` | 米色短衣中性孩子，四向行走；不分男女 | 每秒 6 帧 |
| `elder/` | 灰发、无胡须、中性宽袍与拐杖，四向短步 | 每秒 4 帧 |
| `baby/` | 中性襁褓婴儿，躺卧胸部轻微呼吸 | 每秒 2 帧 |

| 文件方向 | 观察标准 |
| --- | --- |
| `down` | 正面朝下，脸与胸口、脚尖朝向一致 |
| `up` | 后脑和背部朝向观众，不强行保留正脸 |
| `left` | 自然左侧脸，身体和步态一起向左 |
| `right` | 自然右侧脸，身体和步态一起向右 |

## 制作约束与验证

相机与灯光固定，将骨骼及四个脚踝、膝盖 IK 控制器放入同一个方向根；网格继续挂在原骨骼下。建立父子关系时保留 parent inverse，避免动作关键帧将脚拉回转向前的位置。头骨不另加朝镜头约束。

每个身份的四向共用同一个 Root 地面点、正交相机及完整画布；具体骨骼和地面点按原模型测量，保存在各自规约中。方向变化后，求值顶点与理论刚体旋转均须满足 `1e-4` 个单位身高的误差限制；实际各组误差在 `1.2e-7` 以下。这仅证明模型和 IK 一致转向，不能代替脸型与步态的视觉验收。

四类人物均分别测量鞋子范围，鞋底采用刚性脚骨权重，避免后跟被小腿拉低。男村民旧版鞋底曾被小腿和大腿权重拉扁，现已切换到同一刚性鞋底流程，保留原始模型精度。每类均保存 `foot-validation.json`，检查鞋底相对脚骨的刚性残差、缩放及方向。四帧分别检查左右鞋底与指定抬脚高度；老人另记录杖尖高度，不能以“模型最低点为零”代替支撑脚接地。当前老人采用双手握杖的短步候选，经过姿势时上身和杖轻抬；手部与杖保持一致，不宣称已完成所有自然拄杖细节。婴儿只改变胸部和襁褓蒙皮，头部保持稳定，现有移动业务不变。

由于鞋子前后位置在俯视投影中不同，各方向最下方不透明像素不必相同，禁止逐张裁边、重新居中来强行对齐。使用公共地面锚点检查接地。

打开 [素材对照页](../review.html) 可同时播放所有身份，查看四向放大图和 390 像素屏宽下的比例。各目录的 `manifest.json` 保存帧哈希与帧率。原生小场景使用四类人物向下四帧和婴儿躺卧四帧，完整四向仍由对照页检查；本组未进入生产游戏。

## 后续接入边界

四向行走候选已覆盖所有可行走身份；成年男女的耕作、伐木、照料，老人的休息与各身份自然停姿仍需补齐。工作动作须朝向树木或孩子。正式游戏行走及驻足伐木/照料仍有镜像规则，高清资源接入时必须连同方向契约替换，不能直接换图后继续整图镜像。孩子/老人地图、肖像、家谱也需同步到中性共用映射。当前未改这些业务表现代码或存档，精英继续复用所属身份素材。
