## 重现命令

先运行 `node res/tools/hd2d/build-probe-assets.mjs`，再从 Laya 菜单执行“工具 → BuildHd2dProbe”。最后在仓库根执行：

```bash
node res/tools/hd2d/verify-probe.mjs \
  /Users/happyelements/Downloads/daidai-hd2d-20261113/native
```

原生菜单在采样前记录 `captureInputs`，包含原图、派生纹理及导入配置、场景脚本、表现配置、动画和裁切配方；采样后再次比对，保存场景与三种塔预制体的 `captureOutputs`。验证脚本首先比对这些采样时哈希；图片、位置、脚本或保存场景有任何变化，均须重新运行 Laya，不能将验证时的新哈希附给旧截图。

随后读取当前 `DefenseConfig.PATH`，重算派生道路贴图的 505 点覆盖，校验动作 UUID、按钮类型、三层场景关系、火堆内部层次、纹理哈希及统计，并更新本目录的原生采样、六张遮挡图与来源清单。`validationInputs` 单独记录验证脚本、业务路径与脚部报告的版本，不混作原生采样来源。

独立预览由只挂在本场景上的 `Hd2dProbeViewport` 等比缩放并裁剪完整画布，响应 stage 的尺寸变化；不改共享 Workshop 或游戏的分辨率设置。编辑器采样不执行该缩放，继续保持 720×1040 原始坐标。

## 微信开发者工具验证

2026-11-13 已将本小样独立导出至下载目录，并在微信开发者工具 2.02.2609250 Stable ARM64、基础库 3.17.6 中实际运行。导出构建为 `Success`，108 个复制输入与制作源哈希一致，45 张试样 PNG 在微信导出后保持原内容。完整 [验证报告](/Users/happyelements/Downloads/daidai-hd2d-20261113/wechat-validation/验证报告.md) 包含截图、逐动画结果及来源清单。

- 覆盖 320×568 短屏、390×844 的 iPhone 12/13、412×923 的 Pixel 9；画布完整显示，但固定比例小样在三种尺寸上均有上下灰边，尚不能视为正式全面屏或安全区适配完成。
- 微信原生调试器的 `gameContext` 内，每个机型采样 25 次、间隔 137 ms；男、女、孩子、老人、婴儿、山匪与火焰七组均采到全部预期帧，节点坐标、尺寸及 pivot 在采样内保持稳定。这验证帧切换，不代替步态、脚底或最终美术验收。
- 最终控制台为 0 个错误、1 个微信基础库 HarmonyOS 平台支持提示。短屏切换后曾出现一次“模拟器长时间没有响应”提示，关闭恢复后短屏、长屏动画均采样通过，后续切换未再出现；根因仍待定位，不能据此宣称稳定性完全通过。
- IDE 已恢复到 iPhone 12/13。此次仅操作下载目录中的独立验证包，没有改动正式游戏代码、运行图集或 `tryVersion/wxgame`，也没有上传版本或进行手机真机测试。
