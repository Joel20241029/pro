# 人物与怪物动作候选

## 当前可用的小场景试样

| 文件 | 来源与用途 |
| --- | --- |
| `male_walk_1.png`～`male_walk_4.png` | 早期 Blender 四姿态历史图，512×512；已被 `../directions/male/` 鞋底修正版替代，不再由 Laya 加载 |
| `raider_front_walk.png` | AI 生成的正面略俯视山匪两帧原图；统一头部比例、脚底基准及左上光向，武器与头巾不交换左右 |
| `sources.json` | 山匪完整生成提示词与状态，以及未采用的男村民 AI 步态记录 |

山匪只做正面略俯视，不制作侧面或背面。道路改变角色位置，不通过翻转整张图切换朝向。两帧共用裁切画布，以每秒 6 帧播放；当前已在 Laya 原生小场景运行，仍需检查正式弯路移动、实际战斗大小和完整阴影。

十种怪物的正面造型见 [怪物设计稿](../06_怪物正面造型.png)。该稿是五种小怪与五种首领的造型候选；除山匪试样外，其余九种正式动作尚未完成。不能直接把设计稿切成头像就记为动作资源已完成。

较早的两轮 AI 男村民步态因左右脚未真正交替、身份漂移而未采用，失败原图放在下载目录。当前男村民四向行走位于 `../directions/male/`，使用实际骨骼姿势渲染，避免将同一张图位移冒充步态。
