# 高清建筑升级设计

这里保存三种塔、民居及村内设施的阶段造型对照，不进入微信资源包。全部使用 `00_用户确认美术基准.png` 的材质与光照；旧升级稿只提供结构进阶依据。

箭塔、石塔、寒塔分别一张 1/4/8/12 级对照。民居同时展示修缮等级和 2/3/4/5 间扩建关系；设施稿覆盖无围栏农田、伐木场与城门。中间等级的变化、部件拆分、动画与范围数据仍须在原生编辑工程中制作。

设计稿由内置 `image_gen` 生成，不是引擎截图或 Blender 渲染。完整提示词见 `prompts.json`；它们不代替可编辑预制体与正式透明原图。

用户已确认“数据”指尺寸、位置、占地和遮挡；不修改伤害、产量、升级费用等玩法数值。高级造型必须受原生 `VisualBounds`、`Footprint`、`SortOrigin` 和 `Muzzle` 约束，预留村民通道。双弩、锯木装置和水车是外观表现，不新增攻击次数或生产系统。
