# 怪物奇幻重制方向稿

本目录保存 2026-11-16 怪物重制的概念稿、生成提示词与确认记录。正式动作母稿、裁剪参数和游戏发布图仍归入 `res/source/rendered2d/`，不直接把此处整张展示稿打入游戏。

| 文件 | 用途 | 状态 |
| --- | --- | --- |
| `01_十类怪物方向稿.png` | 五种小怪、五种首领的轮廓与材质方向 | 用户已确认造型方向；动作验收另记 |
| `prompt.md` | 本张方向稿的完整生成提示词及工具记录 | 原始制作记录 |

生成工具：内置 `image_gen`，无参考图输入，非透明概念展示稿。高清预渲染二维风格；后续正式帧图需要透明背景、统一相机和光源、独立接地影。

对应设计：[长期经营、五塔防线与怪物重制](../../../doc/tech/46_长期经营与怪物重制.md)。原始生成文件已复制到本目录，工程不依赖工具缓存目录。

十类正式动作母稿位于 `../../source/rendered2d/generated/enemies/rework/`；各类 `.generation.json` 保存原始提示词、输出路径与修订意图。小怪6帧、首领8帧，共70帧。游戏仅发布规范化裁片图集，不发布本目录概念展示稿。透明背景与步态修订仍使用内置 image_gen；Laya源工程保存每类独立预制体与配饰挂点。
