# 百毅靓之怒：强化表现备选

日期：2026-11-14。2026-11-15用户明确选择B旋刃光环并要求实施；A/C仅保留为备选历史。此处仍为概念效果图，正式制作及验证见 [43 旋刃光环](../../../../doc/tech/43_旋刃光环表现升级.md)。

## 调整目标

用户反馈1.0.20的技能表现非常不明显。本轮以实际微信IDE截图为场景参考，放大强化状态的红色轮廓，增加乳白亮芯与深红外缘，并分别展示发动瞬间和持续期间。场景维持正常明亮度，用于比较实际手机画面占比下的辨识度。

## 文件用途与区别

| 文件 | 主要表现 | 取舍 |
| --- | --- | --- |
| A_赤焰附刃.png | 武器周围的红金刃状冠冕，发动时短闪，持续时起伏 | 爆发感强，需避免被误认为塔身着火 |
| B_旋刃光环.png | 两道宽红白弧刃围绕武器旋转，强化标记辅助识别 | 整屏最醒目，需控制前后遮挡和横向占地 |
| C_战旗鼓舞.png | 武器上方红色战旗展开并轻摆 | 状态清晰且画面清爽，爆发感较弱 |
| generation.json | 内置image_gen两轮提示词、原参考和输出路径 | 供重新制作与迭代追溯，不进入发布包 |

用户选择B，原始透明制作图与提示词见 [旋刃素材](../../../source/effects/tactic-rage/README.md)。此处概念图不作为运行或真机验证证据。

## 使用边界

- 本轮只比较技能外观，不改变伤害+50%、15战斗秒、每夜一次及学习条件。
- 图中“伤害强化”是概念演示标签，正式技能名称仍为“百毅靓之怒”。生成图中HUD、人物名或建筑细节的偏差不属于改动要求。
- 不新增火焰伤害、旋刃伤害、护甲穿透或范围爆炸。三方案均可优先探索少量二维贴图与帧动画，延续无粒子系统的要求；实际资源量须以制作结果为准。
- 选定后须分别校验箭、石、寒三类塔以及不同等级；只在有驻守的塔上显示，使用结束收起，保持武器、道路、敌人和塔下文字清晰。
- 图稿不得直接当作可用贴图裁切接入。正式制作需单独产出透明源图并维护导入配方与图集。
