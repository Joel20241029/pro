## 设计边界

- 用户确定入口在排行榜下方；达到波数后开放学习，支付木材与粮食才能学会。
- 1.0.19 仅包含“大王之心”；1.0.20 加入“百毅靓之怒”（守住3波、40木20粮）。图中的“待定战技 A/B”用于演示可学习、未达波数和详情排版，名称、效果、波数与价格不作为正式配置。
- 明亮田园风格沿用已确认的配色。左侧场景用于交代入口位置，不代表修改当前地图、美术、建筑或人物。
- 右上关闭、返回层级、图文居中、按钮安全区及短屏塔位遮挡需在 Laya / 微信 IDE 实绘时核验；设计图不能证明已经完成适配。
- 后续正式素材需单独制作与采样，更新源文件、配方、台账及正式图集；不能将整张设计图切片直接替代可伸缩 UI。
