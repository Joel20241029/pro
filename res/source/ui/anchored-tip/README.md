## 制作配方

`../../asset_recipe.json` 是唯一裁切与缩小依据：

- `panel_anchored_tip`：主体原图矩形 `(173,134,1325,455)`，先转换为 `96×40`，保留四边各 `10` 像素，中心压缩为 `2×2`，最终九宫格 `22×22`。
- `panel_anchored_tip_tail`：指角原图矩形 `(1755,318,239,172)`，缩小为 `20×14`。独立绘制，不随底板宽度拉伸。
- 两者都是 `ui/panels` 分类，只新增图集条目，不新增图集页。原图透明边及孤立像素由显式源矩形排除；运行图集仍只裁透明外圈。
- 运行底板为浅米黄、边缘为暖棕色；建筑气泡正文使用 `C.tipInk`，主体与指角重叠 `6` 个设计像素，遮住主体下边缘的中段接缝。
- 屏中提示正文使用现有 `C.timber`（`#9a591f`），搭配浅色细描边；保留 2 秒淡入淡出。旧 `panel_tip` 已设为备用，只保留原图和配方，不再进入运行图集。

在仓库根执行 `node res/tools/build-resources.mjs --work <Downloads 内工作目录> --sync` 重建。输出到 `res/runtime/ui/panels/`、`res/atlases/` 及游戏工程资源目录，勿反向修改输出文件。
