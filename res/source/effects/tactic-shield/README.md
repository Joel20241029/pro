# 二楠之盾原始素材

本目录保存2026-11-15确认的青蓝透明护罩原稿与生成记录。`shield-sheet.png`是1536×1024透明PNG；`generation.json`保留完整提示词与参考设计路径。原稿不直接进入小游戏。

| fx_shield_ring | 64,680,640,184 | 256×80 | battle |
| fx_shield_hit | 960,590,380,370 | 96×96 | battle |

正式裁切和采样配方位于`res/tools/hd2d/prepare-production.mjs`。图标清理低于32/255的alpha；光效将24/255以下底雾连续归零、以上alpha线性拉回0～255，避免硬阈值造成透明断层。高光与柔边保留，不画入城门、地面或文字。

运行时复用一张护罩、一个贴地环、一个扫描环和三个抵挡涟漪节点。罩体跟随实际城门Body范围，门后/门前两层独立排序；不扩大建筑点击或人物遮挡框。动画使用战斗tick，暂停冻结、倍速同步、结算立即清理，不使用粒子或序列帧。原图、派生图、资源配方与图集必须一起维护。
