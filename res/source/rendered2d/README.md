# 高清二维离线制作源

这里保存用于制作二维帧的可编辑模型、骨骼、材质和渲染参数。它们不进入微信主包、人物包或战斗包；游戏仍使用二维图片。

## 当前内容

| 目录 | 内容及状态 |
| --- | --- |
| `characters/male/` | 男村民高精源模型、四个行走姿势和 Blender 工程。已输出透明帧并在 Laya 小场景播放，尚未通过完整美术验收 |
| `characters/female/` | 女村民原始 PBR 模型、独立骨骼参数、四向行走工程与追溯 |
| `characters/child/` | 中性孩子原始 PBR 模型、大头短身骨骼、四向行走工程与追溯 |
| `characters/elder/` | 中性老人原始 PBR 模型、短步与刚性杖控制、四向工程及鞋底/杖尖记录 |
| `characters/baby/` | 中性婴儿原始 PBR 模型、躺卧呼吸骨骼工程及记录；没有行走 |
| `environment/` | 苹果、火堆和前石遮挡层的真实 Blender 工程；其他环境生成图仍在设计目录 |
| `characters/generation-prompts.json` | 新四类村民的完整生成提示词、参考图和参数，不含访问凭证 |

这些文件是可继续修改的制作候选，不能因进入本目录而视作已验收。全部村民适用男村民的画质、朝向、帧对齐标准；劳动、休息与正式投影仍需完成。怪物的完整离线制作源尚未齐全。静态 AI 造型稿仍存放在 `res/design/hd2d/`，不会被标为三维渲染源。

正式运行素材的接入以 [技术文档 32](../../../doc/tech/32_高清预渲染二维美术重制.md) 的阶段与验收要求为准。
