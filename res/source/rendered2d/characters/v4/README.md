# 大头 Q 版村民

`approved-proportions.png` 是本轮确认稿。成人保留原服装、发型和配色，头部加大，身体、手脚缩短并加宽。盔甲、披风、帽檐和发饰随各角色一起调整。儿童、老人和摇篮婴儿应用同一造型方向。

## 文件

- `renders.json` 保存动作帧、足点和落斧帧。每个角色目录保存母片、可编辑 Blender 工程和测量报告。
- `rig-profile.json` 保存角色形变比例、足点及整周期步幅。行走仍有八个独立渲染方向。
- `labor-poses.json` 保存工具动作和盔甲、披风经检查后使用的站姿微调。`labor/labor-report.json` 记录握柄位置、刃口坐标、贴地高度和网格相交检查。
- `authoring/` 保存模型变形、工具动作和摇篮的生成脚本。基础模型、材质与固定光照继承相邻的 `v3/` 制作工程。

## 验收

八类可移动角色重新求解左右脚落地。婴儿脸部在既有呼吸形变中调整，底部锚点用于地图摆放。横劈保留五帧，锄刃高度分为抬起、下降、接地和回收。剑的护手、握柄和剑身为独立部件。工具跟随重新计算的手掌位置，动作生产时检查刃口是否与角色网格相交。

重跑 `res/tools/hd2d/prepare-production.mjs`，将制作配方同步为 `res/source/asset_recipe.json`，再运行 `res/tools/build-resources.mjs --sync`。两个工具都使用位于 Downloads 的 `--work` 目录。发布图集保留村庄和守夜两个下载阶段。
