# 怪物制作要求

这是本轮采用的制作规格摘要，供后续迭代；不是逐字恢复的生成请求记录。原始生成文件路径、SHA256、尺寸记录在 `../generation_records.json`。

- 与已有山匪、疾行匪、甲兵、扰阵师、匪首保持像素风、棕色描边、低饱和林地色和俯视三分之四角度。
- 新底型为四足野猪、持盾重甲统领、大尾狼王、宽体獠牙兽王、长臂持杖山魈长老。每种四帧行走，肢体交替，轮廓辨识优先。
- 透明背景，无文字、网格、地面、投影或外部光晕；各帧和各行留出透明间距。
- 五行四列，同行共用比例，不逐帧拉伸；配准画布为 96×96，足底坐标为 (48,92)。首帧与末帧能够循环。
- 配件独立六格：短头带、小鹿角、三根羽饰、背部短旗、小簇叶饰、木面具。不要把配件烘焙进角色底图。
- 身体中间调可以染色；眼睛、牙齿、粉色口鼻、重要深描边与鲜明饰物保持原色。拆层由配方自动生成，身体和细节不可分别裁成不同原始画布。
- 配件必须使用各底型的合法清单，不以装饰颜色暗示额外元素伤害。
