# 民房点击气泡预览

日期：2026-11-12。左侧民房显示“佟楼”，右侧显示“南楼”。本目录只供设计和验收，不进入微信发布包。

- `设计稿.png`：用户已确认的组合设计稿，由母版生成，用于确认颜色、轮廓和文字大小。
- `游戏实绘_*.png`：LayaAir IDE 3.4.2 使用正式 GameView 和实际图集绘制，包含短屏、iPhone 12 比例及不同住宅等级。它们是原生引擎夹具图，不是手机截图。
- `tip-behavior-check.json`：各场景的命中、挂点、计时、重排和生命周期检查。
- `game-render-check.json`：完整 26 张原生绘图索引；本目录只保留代表图，完整输出位于 `~/Downloads/daidai-building-tip-20261112/native/`。

气泡从指角尖端放大展开，停留后缩回同一点，总计 `2` 秒；重复点击重新计时，切换民房替换名称和目标。打开面板或重开村庄立即收起。

制作源见 [气泡母版](../../source/ui/anchored-tip/README.md)，实现及验证边界见 [技术文档 26](../../../doc/tech/26_建筑点击气泡.md)。
