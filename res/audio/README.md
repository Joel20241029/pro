# 运行音频

| 文件 | 用途 | 时长 | 文件大小 |
| --- | --- | --- | --- |
| `village_loop.mp3` | 日间循环，沿用原曲 | 24 秒 | 96,462 字节 |
| `battle_loop.mp3` | 无鼓夜战循环，小调拨弦与低音弦乐 | 16 秒 | 64,488 字节 |
| `ui_click.mp3` | 短操作声 | 0.085 秒 | 854 字节 |
| `tower_fire.mp3` | 三种塔共用的短发射声 | 0.09 秒 | 854 字节 |
| `enemy_defeat.mp3` | 小怪与首领共用的首版短击倒声 | 0.28 秒 | 1,585 字节 |
| `patrol_flight.mp3` | 巡防角色飞行中的循环气哨，音高先升后降 | 0.96 秒 | 4,302 字节 |
| `patrol_landing.mp3` | 巡防角色落地时的一次踏土声 | 0.24 秒 | 1,481 字节 |
| `patrol_rapid_fire.mp3` | 机关枪实际扣弹时的短促发射声 | 0.085 秒 | 854 字节 |

`manifest.json` 保存时长、字节和哈希。制作源位于 `../source/audio`，生成脚本为 `../tools/build-audio.py`。所有音乐和音效随微信主包提供。发射声按实际齐射触发，现实时间 120 毫秒内至多一次。击倒声随死亡表现开始播放，相邻两次播放至少间隔 450 毫秒。各音轨共用游戏声音开关与微信音频中断生命周期。

淡紫机关枪每次实际发射播放一声，命中时显示「额！」字效。

上述时长是制作时长，MP3容器包含少量编码补齐。手机扬声器音质需实际试玩确认。
