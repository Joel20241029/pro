# 三包发布成品

base 为主包素材，characters 为人物原生分包，battle 为守夜原生分包。这里是有资源归属的最终制作输出；引擎同步按 manifest.bundles 的白名单执行。图集与帧表不跨包引用，README 不复制到游戏。

`../atlases/` 保留整体图集审计与帧索引，真正发布以这里为准。每包说明见对应子目录。


每包新增 `particles.json`：base 包含升级、按钮和共享材质；characters 包含精英脚底圈；battle 包含三类拖尾、三类命中和撞门。无新 PNG。粒子数据随所属包完整校验后才开放使用，失败仍由原有下载面板重试。
