# 界面文案精简

2026-11-16，版本 1.0.31。面板首屏优先呈现图标、读数和当前可执行的操作。开村、村民、家庭、家谱、建设、塔位、来敌、守夜、战技、好友榜、小记及各类结算和存档提示逐一核对。

## 费用与状态

- 建造、改建、升级、修门、迎接孩子和学习战技使用现有资源图标。可支付时显示所需数量，缺材料时用红色显示现有／所需。极大的库存读数可缩写，扣费所需量以完整数字显示。
- 需要选人才能完成的操作在最后一步仍能看到准确费用。建设时段、仓储、住房、孩子及照料者条件在相应条目显示。
- 顶栏保留粮、木、人的简写。底栏用粮食和木材图标配正负数显示产出与口粮。守夜预览保留每种敌人的数量、特性、驻塔人数和缺粮后果。
- 重开确认说明将清空的内容。恢复进度、存档版本不符、损坏或冲突、保存重试有各自的提示。满仓口粮显示到账 0，并说明确认会计作已领取。

## 布局

建设和家庭价签贴近操作。塔位用三张并排卡片列出防塔类型与费用。战技列表保留查看详情入口，详情直接显示效果。清晨专长与村规把名称和数值放在同一行。名册和家谱继续按窗口挂载条目。小记收为声音、玩法说明和重开三个入口，进阶规则从玩法说明查阅。
