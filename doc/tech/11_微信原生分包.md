## 2. 发布配置与启动顺序

[BuildSettings.json](../../project/LayaProject/settings/BuildSettings.json) 启用 `enableSubpackages`，声明：

```json
{
  "path": "resources/village",
  "packAllAssets": true,
  "autoLoad": false,
  "remote": false
}
```

`packAllAssets` 保证动态引用的两张图集与两个 JSON 都导出；`autoLoad: false` 让 Main 的加载界面先出现，再主动加载资源包。Laya 发布器输出的 `game.json` 包含：

```json
{
  "subpackages": [
    { "name": "resources/village", "root": "resources/village/" }
  ]
}
```

实际启动顺序：

1. 主包初始化 Laya，进入原有 `Scene.ls`，显示“正在准备村庄资源…”。
2. [Main.ts](../../project/LayaProject/src/Main.ts) 调用 `await Laya.loader.loadPackage(VILLAGE_RESOURCE_PACKAGE)`。
3. 微信适配器调用 `wx.loadSubpackage`；成功后 Laya 读取并注册资源包 `fileconfig.json`。
4. 确认返回 `true` 后，显示“村里的灯火正在亮起…”，由 [SpriteFrames.ts](../../project/LayaProject/src/view/SpriteFrames.ts) 加载页表、动画配置和两张图集。
5. 创建村庄界面、移除加载文字，再执行 `session.load()` 读取存档或显示开村面板。

常量 `VILLAGE_RESOURCE_PACKAGE` 与发布配置一致，图片运行地址仍为 `resources/village/...`。依据包括本机 `engine/types/LayaAir.d.ts`、实际发布器与导出引擎实现，以及 [Laya 官方微信分包说明](https://layaair.com/3.3/doc/released/miniGame/wechat/readme.html)。本机 3.4.2 的 `loadPackage` 返回 `Promise<boolean>`，不能只依靠异常捕获判断成功。

## 3. 失败与生命周期

- 原生下载或包配置加载失败返回 `false`，Main 主动报错；Promise 异常走相同错误展示，延用原有“启动失败，请重新打开小游戏”行为，不创建缺图村庄、不自动重试。
- 分包等待中销毁场景时，释放加载文字并解绑前后台监听；晚到结果停止后续加载。
- 图集等待中销毁时，在 Promise 完成后再次释放异步新建的子纹理；晚到异常不写入已销毁的文字。
- 使用分阶段提示。当前适配器的原生进度为 0～100，后续文件读取进度口径不同，没有把两者混成会倒退的百分比。
