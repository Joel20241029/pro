# 战技系统实施与 1.0.19

日期：2026-11-14。依据：已确认的 [40 守村战技系统规划](40_守村战技系统规划.md)。状态：实现、正式导出与上传完成，微信平台回执确认成功，并覆盖当前体验版；实体手机试玩仍待验证。

## 1. 本次功能

- 首次成功守住一波后，地图左侧出现“排行 / 战技”两枚入口；已有最高纪录的重开村保留入口。波数学习门槛使用当前村庄成功防守数，不使用最高纪录。
- 正式目录只有原有“大王之心”：初始学会并携带、免费使用、每夜一次、全塔攻速 +50%、15 个战斗秒；暂停冻结、倍速跟随、原施放资格不变。
- 通用流程支持达到波数后消耗一次木材和粮食学习并携带，白天免费切换，夜间只能查看。没有加入用户尚未指定的新技能、价格或效果。
- 战技列表与详情复用现有绿色面板、奶油卡片、金绿按钮和滚动组件；条目在每次进入时排序，返回保留顺序和滚动。单技能目录使用紧凑高度。
- 战前面板新增“今夜携带 / 更换”；从战前学习或切换成功后返回战前，从普通详情操作成功后回列表，过程继续保持面板暂停。
- 红点仅在白天存在真实可学习且材料足够的未学会战技时出现。当前只有已学会的初始战技，因此不会出现虚假购买红点。
- 传承保留已学会集合，新村默认携带大王之心；纯净开始清回初始战技，最高成绩仍遵循原规则。

## 3. 资源及主包

新增唯一原图为 [战技卷轴](../../res/source/ui/tactics/README.md)，正式 ID `icon_tactic_scroll`。派生画布 96×96，入口显示 44×44 逻辑像素，透明边裁切并保留抗锯齿；现有图片没有降尺寸或减色。

制作链：原始透明 PNG → `prepare-production.mjs` → `production_recipe.json` → `asset_recipe.json` → `build-resources.mjs --sync` → Laya 导出。共 344 项素材、48 组动画、13 页图集；建筑、人物和战斗分包不增加内容。

首轮主包 4,195,847 字节，超出 4 MiB 1,543 字节。主包 PNG 大图无损搜索从 5 轮提高至 15 轮，资源总字节再减少 9,364；构建器逐字节比较解码 RGBA，尺寸、颜色和透明度不变。

最终本地导出：主包 4,186,549 字节（约 3.993 MiB，余 7,755 字节），建筑 3,067,814、人物 6,678,000、战斗 1,912,727 字节，总目录 15,845,090 字节。发布白名单、资源合同、原图/工程/导出一致性检查通过；未夹带设计稿、测试代码或示例技能。
