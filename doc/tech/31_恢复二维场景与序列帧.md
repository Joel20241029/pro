日期：2026-11-13。状态：二维代码、原图集、序列帧及微信导出已恢复；自动测试与开发者工具基础流程验证通过。真机与本轮完整视觉逐项复验尚未完成，证据范围见第 5 节。

## 1. 最新决定与恢复范围

用户明确取消全场景实时 3D，也取消 3D 转二维方案，恢复原来的二维表现。恢复依据是原图集、原序列帧、已有 Laya 部件建筑与二维粒子制作源，不以新生成模型的截图替换原美术。

| 对象 | 已确认处理 |
| --- | --- |
| 场景 | 恢复二维地面、道路、树木、草花果、围墙、路牌、火堆和其他装饰 |
| 村民 | 恢复原性别、年龄、岗位对应序列帧，按原方向与足底定位；包含婴儿、男孩女孩、男女成人与男女老人 |
| 怪物 | 保留 5 小怪＋5 首领、原序列帧和组合外观，不回退为早期五怪版本 |
| 建筑 | 恢复七类独立原生二维预制体转换的部件布局、等级与房数变体和共享时间轴 |
| 弹道与特效 | 恢复二维飞行图片、命中粒子、精英脚底圈及大王之心红色按钮粒子 |
| UI | 保留高清矢量面板、按钮、图标和现有排版；人物头像恢复原人物帧，不使用 3D 渲染头像 |
| 发布 | 继续 base、characters、battle 三包和原分阶段准备流程，只发布运行白名单 |
| 历史源 | 3D 模型、world3d 编辑源及试验记录保留追溯，不加载、不发布、不转二维成品 |

本轮不调整生产、养育、寿命、精英、升级成本、伤害、射程、波次、技能、每日口粮、纯净开村、排行榜或存档业务规则。不能为恢复画面顺便回退这些已确认功能。

## 2. 二维实现边界

### 建筑与遮挡

沿用 HOUSE、FARM、LOGGING、GATE、ARROW、STONE、SLOW 七个独立预制体，以及原有 108 种等级与房间组合的制作结构；运行只创建当前变体。民居修缮与扩建房数分别表达，不将房数误作为修缮等级。

恢复 `VisualBounds`、`Footprint`、`SortOrigin` 与 `Weapon/Muzzle` 语义。足底与导航占地保持同源；农田地面可行走，水车独立遮挡。原时间轴跟随游戏视觉时钟，面板暂停、倍速和重开清理不能改为独立引擎计时。结构数量、实际提取结果与挂点仍需本轮构建验证。

### 人物、怪物与图集

恢复原帧画布、透明裁边偏移与 pivot，不能只按裁后图宽高居中，否则会造成走路跳动和脚底漂移。人物头像复用对应原帧，保留性别与年龄辨识。十类敌人的共同足底、身体染色、细节帧和兼容配件沿用已有二维方案；外观随机不得改变业务随机流或战斗数值。

### 粒子与动作反馈

沿用 [29 第 11 节](29_粒子特效与动作反馈.md#11-1013-表现精简与红色可用提示) 的六种二维粒子：底包 1 种大王之心按钮环绕，人物包 1 种精英脚底圈，战斗包 4 种命中效果。

大王之心使用鲜红色 `#f04435`，按既有夜战未使用且未暂停的可用条件沿按钮内缘环绕；粒子与按钮面层一起按压，不引用刷新后已销毁的旧按钮。既有初始尺寸 7、每秒发射 40、寿命 0.65 秒、每圈 2.6 秒、最多 32 粒参数保持。技能效果和持续时间不因表现恢复而改变。

攻击拖尾和建筑升级粒子继续移除；飞行图片、命中效果、怪物实际受伤红闪、落斧树摆及建筑自身升级动作保留。命中反馈沿既有视觉事件触发，不改变业务扣血时点；纯减速不制造受伤红闪。面板打开、切后台、倍速、天亮与重开均需检查生命周期。
