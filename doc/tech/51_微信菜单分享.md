# 微信三点菜单分享

## 接入范围

2026-11-16，接入微信小游戏右上角“…”菜单中的发送给朋友／群聊。标题为“你能守住多少波？”，使用已制作的 500×400 分享图。仅注册被动分享，不主动发送消息，不获取群信息，不增加分享奖励或排行榜权限。

## 实现与资源

- `WechatPlatform.bind()` 保留原前后台事件注册，并在分包下载前调用 `wx.onShareAppMessage`、`wx.showShareMenu`。`Main` 无需增加调用层。
- 回调使用稳定引用，每次同步返回新的标题／图片路径对象；`unbind()` 将同一引用传给 `wx.offShareAppMessage`，不清除其他监听。
- 注册成功后标记持有，重复绑定不重复注册；启用菜单失败不清除持有标记。接口异常只写明确日志，不阻断启动、不自动重试。解绑失败保留持有状态，继续原前后台事件清理。
- 配置位于 `project/LayaProject/src/config/ShareConfig.ts`；原稿、发布图和制作说明位于 `res/branding/share/`。
- 模板图片位于 `project/LayaProject/build-templates/wxgame/share/village-share.jpg`；发布后相对路径为 `share/village-share.jpg`，属于主包，不依赖任何分包或远程图片下载。
- 图片为 174,401 字节 JPG，SHA-256：`7180339a79d80ec3d7fe88d22c4b6cc167cdd376e70e8ae9893c5b785111f579`。高清原稿不进入发布包。

## 微信官方依据

- [onShareAppMessage](https://developers.weixin.qq.com/minigame/dev/api/share/wx.onShareAppMessage.html) 支持本地路径和代码包根目录相对路径，图片比例为 5:4。
- [showShareMenu](https://developers.weixin.qq.com/minigame/dev/api/share/wx.showShareMenu.html) 开启 `shareAppMessage`；本项目 `withShareTicket=false`，不请求群数据。
- [offShareAppMessage](https://developers.weixin.qq.com/minigame/dev/api/share/wx.offShareAppMessage.html) 通过相同监听函数引用精确解绑。
- [分享能力指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/share/share.html)：后台审核图片的 `imageUrlId` 与 `imageUrl` 需配对使用。本次使用包内图片，不虚构已审核素材 ID。
