# 村民自主行为与建筑遮挡

日期：2026-11-10。范围：微信首版表现层修复。源工程为 [LayaProject](../../project/LayaProject/)。

## 1. 问题与修复方案

原实现将民居、农田放在 scenery，将村民与敌人放在 actors，将防塔与城门放在 chrome。这使房屋永远在人物后面、塔永远在人物前面，无法形成实际前后遮挡。同时多数村民只有原地序列帧，待安排人物仅小幅正弦摆动，没有地图行走。

沿用原设计要求的「程序位移」与「脚底逻辑 y 排序」，本次采用固定站点、建筑占地可见性图和轻量行为循环。固定前后层无法表达走到屋后的变化；完整物理、人群系统又超出当前固定小地图需要，因此没有增加此类依赖。实施前已做独立可行性审查，完成后再次复核。

## 2. 可观察行为

| 人物状态 | 行为 |
| --- | --- |
| 耕作 | 从当前位置走到农田外侧工作点，停留劳动，再到村内休息点，循环返回 |
| 伐木 | 走向树木/伐木点，停留劳动，再往返村内休息点；往返使用与移动方向一致的行走帧 |
| 待安排 | 在住宅后方、村中空地、火堆旁和家前站点之间散步、驻足 |
| 照料 | 前往孩子家附近站点，停留照料，再返回自己的表现站点 |
| 婴儿 | 在家前固定位置播放待机，不自行行走 |
| 孩子 | 在家前活动点之间短距离走动；成年时保持脚底位置并更换行为 |
| 夜间驻守 | 向当前防塔前侧站点移动，抵达后视为进入塔内，隐藏人物；战斗结束重新显示 |
| 夜间其他村民 | 返回家前站点停留 |
| 在村老人 | 男女各一套白发造型，白天以 24 逻辑像素/秒在家前与休息点间慢走和驻足，夜间回家 |

夜间未驻塔村民仍在家前显示。调任其他塔时人物重新出现并步行，抵达再隐藏；释放驻守会显示并回家。只有精灵可见性改变，人物状态不删除。

工作、休息、行走均是视觉行为，不产生额外资源，也不延迟生产、成长或塔攻击。夜间换塔使用本夜 `battle.base.towers`；正式驻守命令生效后塔立即按原有规则攻击，不等待人物抵达。

当前位置、路线和动作时间按人物稳定 ID 保存于内存。刷新菜单、保存成功、查看资源不会重置人物。荣休时保留当前脚底，换老人外观并重规划晚年日程；寿终才移除其表现状态，新村清理上一局表现。移动本身不写入存档，也不消耗世界、家庭或战斗随机流；业务新增的 elderNights 与 night.elders 见 [08](08_晚年生活与滑动列表.md)。重进游戏从预定家前站点重新展开表现，不保存离线移动。

## 3. 寻路与遮挡

- [VillageScene.ts](../../project/LayaProject/src/view/VillageScene.ts) 复用现有地图位置。占地仅覆盖地面底座，不用整张屋顶、树冠矩形堵路。
- 在底座外增加 7 个逻辑像素足底间距；预计算可见角点和静态连线，只有目标改变或抵达后进入下一行为时才寻路。
- 路线线段用矩形相交检测，避免稀疏采样漏墙。不可达站点作为地图配置错误暴露，不靠传送或穿墙补救。
- 建筑、树木、城门、防塔、村民、敌人都在同一个 World 下；排序键为脚底 y 与带类型前缀的稳定 ID。
- 排序结果写入 `zIndex`。各层使用 `stackingRoot`，确保世界排序不会盖住 HUD 和面板；依据已安装 3.4.2 引擎声明及 [Laya 3.4 Sprite API](https://layaair.layabox.com/3.x/api/3.4/classes/laya_display_Sprite.Sprite.html)。
- [SpriteFrames.ts](../../project/LayaProject/src/view/SpriteFrames.ts) 使用帧配置中的 pivot，按显示尺寸换算足底。镜像围绕同一足底进行，不参与排序。

行人可以走到屋顶和树冠后方，但不能走入墙基。原敌人道路与到门逻辑保持原实现，村民寻路不修改战斗路径。当前未加入村民之间的人群碰撞、队列或拥挤避让。

## 4. 动画与生命周期

[VillagerMotion.ts](../../project/LayaProject/src/view/VillagerMotion.ts) 保存行为和累计动作时间；[GameView.ts](../../project/LayaProject/src/view/GameView.ts) 使用原唯一帧循环推进和展示。

行走时使用本人行走序列帧，停止后使用本人已具备的劳动动作或静止帧。动作发生变化时重置该动作时间。暂停只停止时间推进，不将行走中的角色突然切成 restFrame。夜间视觉时间取实际战斗 tick 增量，不另外重复乘倍速；白天对长帧做限幅，后台回来不补走离线距离。

成人和儿童四个身份使用正面、背面、右侧三组四帧行走；男女老人另有三组两帧行走及两帧待机，均以右侧镜像提供左向。根据实际位移方向选择，斜向保留 15% 主轴滞回，停止保留方向。原画布和 pivot 经图集裁边元数据还原，不因换帧抖动。森林使用两块合并占地，木栅使用左右两段占地；城门两侧各保留 40 逻辑像素通道。实现详见 [06 视觉升级与资源管线](06_视觉升级与资源管线.md)。未增加骨骼动画或第三方寻路库。

成家后新增双人会合日程与子精灵红心，复用足底遮挡；男女均有耕作、砍树和照料动作，实际触发条件见 [07](07_人物动画审计与自动岗位.md)。
