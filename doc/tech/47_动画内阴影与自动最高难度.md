# 动画内阴影、塔位与自动最高难度

## 1. 范围和已确认规则

本轮目标版本为 1.0.25。用户要求第五塔移到原友谊路路牌上方，路牌放到道路左边；怪物阴影作为动画内独立节点，不烘焙到身体图片。追加确认：从第一年开局就采用原最高 3 档，每年不再弹出难度选择。

## 2. 阴影制作与运行

之前怪物和接地影分别由地图中的节点池管理。本轮将十类怪物的每个独立 Laya prefab 增加根级 `ContactShadow`，放在全部 `Frame` 之前，与身体共用 `SortOrigin` 和父变换。运行使用同一个 Sprite，先 `drawTexture` 阴影，再绘制身体与挂件；不再创建地图层的怪物阴影节点。村民、树木及建筑保持现有阴影。

源配置位于 `res/source/rendered2d/enemy-layouts.mjs`，原生工程位于 `res/editor/BuildingWorkshop`。通过 Laya 的 `Hd2dEnemyRefinementScene.build` 实际保存十个 `.lh` 和验证场景，再由 `build-enemy-layouts.mjs` 导出 v4 合同。完整制作入口 `Hd2dProductionScene` 同步支持阴影，避免下一轮生成时丢失。

复用建筑分包的 `shadow_actor`，战斗包仅增加引用与矩形，不复制图片。Laya `drawTexture` 自身恢复裁边偏移，调用端不二次补偏移。阴影 Alpha 为 0.5，不参与怪物染色和红闪。编辑器将矩形保存为整数，因此 Alpha 中心允许每轴最多 0.5 个原始 96 画布单位的取整误差，实测十类最大 0.493；禁止逐帧追随抬起的脚尖。

静态源坐标与用户截图的偏移未完全复现，本轮不声称已证明手机问题的唯一原因。修正依据是消除独立阴影定位路径，并同时验证原生动画和微信实际渲染。

## 4. 最高档自动生效

- `createGame` 在首个波次生成前设为 `RULE.maxTier`，覆盖普通、传承与纯净重开。
- 删除 TIER 的选择类型、清晨入队、命令分支、面板和存档白名单；状态校验要求 tier 严格等于最高档。
- 专长、旅人和季节村规流程保持，最后一项清晨事项完成后照常生成波次。
- 沿用原数量公式，每夜比原 0 档增加 9 只，首夜为 17 只；不额外改变怪物个体血量、速度、奖励或排行计分。
- 游戏说明同步，顶部移除不可再调整的“挑战3”尾缀。
- CONFIG_VERSION 17→18；沿用版本不一致时明确确认重开，不新增迁移或静默清档。
