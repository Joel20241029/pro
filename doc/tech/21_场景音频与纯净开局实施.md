# 场景音频与纯净开局实施计划

> 实施方式：在当前工程按任务执行，独立任务交给子 Agent，逐项进行需求与质量审核；不提交、不推送。临时报告和验证产物放 Downloads。

目标：完成已确认的场景、美术、声音和纯净开局，动画通过验证后才替换。

架构：保留游戏规则与微信资源分包。存档复用双槽候选，音频复用微信上下文，场景部件共用足底排序。正式人物迁移以编辑器往返和样板画质/体积为前置条件。

技术：Laya 3.4.2、TypeScript、微信小游戏、现有资源构建脚本。

规格：[20 场景美术音效与动画方案](20_场景美术音效与动画方案.md)。

## 全局约束

- 只支持微信；不修改数值、射程、人口和无限成长公式。
- 纯净开始仅保留最高纪录。每次新开村清空领取日期；同村同日重进不重复领取。
- 新增声音合计目标不超过 80 KB；花果和建筑部件目标不超过 120 KB。
- 1～12 级逐级部件变化；13 级起结构封顶，等级牌、徽饰和升级反馈继续变化。
- 不回退已有修改；制作源/配方/发布资源/文档同步；实验和日志均放 Downloads。
