# 微信原生 ASTC 分包

临时采用微信普通原生分包。游戏保持村庄和守夜两个加载阶段。主包保存代码、启动图、音乐音效及排行榜开放域。现有 ASTC 图集、动画和配置按照已有清单放入对应分包。

| 微信包 | 1.0.66 本地导出原始字节 | 加载时机 |
|---|---:|---|
| 主包 | 2,830,743 | 小游戏启动 |
| 村庄分包 | 5,611,982 | 启动画面显示后 |
| 守夜分包 | 812,642 | 打开战前准备或恢复夜间存档 |
| 合计 | 9,255,367 | 两个分包均已下载 |

包内图集只发布 KTX。现有帧表保留逻辑文件名，读取时映射到该阶段的 KTX。原生包里的配置物理文件为 `.vdata.bin`，读取 UTF‑8 后提交给原 Laya JSON 解码，能避开微信包内文件后缀限制。建筑动画仍由 Laya 用 `.mc` 逻辑路径读取导出的 `.mc.bin`。PNG、JPG 原图继续用于制作和编辑器预览。

加载由 Laya 的微信原生桥完成。微信百分数换算到进度条，加载成功后再解码。两阶段复用原有失败重试和任务去重。不支持 ASTC 的微信设备在启动图上看到明确提示。

## 构建和回切

```sh
node project/LayaProject/tools/build-wechat-delivery.mjs <版本> <Downloads任务目录> <Laya CLI> native
node project/LayaProject/tools/build-wechat-delivery.mjs <版本> <Downloads任务目录> <Laya CLI> remote
```

构建入口在隔离副本整理资源，校验后更新正式导出目录。默认使用 `native`。回切时指定 `remote`，复用原来的 Gitee 清单、加载器与缓存。Laya 编辑器直出沿用工程原发布配置，临时原生包使用上述构建入口。

验证使用 Laya 3.4.2 及微信开发者工具。原生包统计取实际导出文件，微信平台统计单独记录。
