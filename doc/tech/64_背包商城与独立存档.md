# 背包和商城

## 开放与界面

- 新村开局和已存在的村庄均可在白天从左侧进入背包和商城。两个入口不需要守夜波数，也不播放解锁演出。两项智卓引导各自记录，均可跳过。守夜收起左侧入口。
- 背包按道具逐行展示图标、名称、库存和用途。巡防道具在本行点「使用」，精华点「选村民」后进入原有的选人和确认流程。无法使用时说明原因，列表可纵向滑动。空包复用入口图标。
- 商城分为「消耗品」和「弹药」，首次打开选中消耗品。两页使用纵向列表，各自保留滚动位置。分类没有商品时在列表区域显示空态。商品卡展示名称、图标、价格和「购买」，可购买时在购买按钮右上角显示红点。未选中的分类有可购买商品时，其标签显示红点。
- 点击「购买」后在确认弹窗查看用途和费用，点击「确认购买」后才扣资源。取消或成功购买后返回原标签和列表位置。成功入档后弹出购买提示。
- 入口和空态共用两张 96×96 图标。资源道具复用游戏现有的粮、木和工具图集。

## 商品配置

`project/LayaProject/src/config/ShopConfig.ts` 中的 `ITEMS` 维护稳定道具 ID、名称、用途和图标。将需要上架的 ID 按展示顺序填入 `SHOP_PRODUCTS`。下架时从数组移除 ID，保留道具定义，背包已持有的道具仍可识别。

`SHOP_PRODUCTS` 中的每项包含道具 ID、粮木价格，并可配置商品详情中的传闻。带 `ammo` 的商品进入弹药页，其余进入消耗品页。当前上架「靓哥的精华」（120 粮、15 木）、「靓哥的底线」与「靓哥的放纵」（各 40 粮、20 木）、「越秀路六家」（20 粮、12 木），以及可在塔上换装的冰弹（35 木）。

## 越秀路六家

白天从商城购买，在背包确认投掷。村庄存档和道具扣除在同笔交易中提交，掷骰动画以保存结果为准。1–3 点使下一场守夜粮木产出减半，4–6 点翻倍。按整数向下取整，并沿用现有的口粮、仓储和开战入账流程。倍率不用于每日口粮、日常任务或探索奖励。

同一夜只接受一次骰子结果。点数在开战时从村庄待用状态移入当夜快照，退出战斗会还原粮木和待用点数。重新进入当夜或存档重试都沿用原结果，下一场完成后恢复正常产出。旧存档字段缺省表示没有骰子效果。守夜准备、战斗右上角和胜利结算会显示倍率。右上角「本夜效果」也会统一显示淡紫儿的两种物品加成及其他整夜状态。

## 靓哥的底线

商城与背包使用同一枚红色男士内裤图标。商品详情显示淡紫儿把红底裤挂上旗杆的趣闻。白天使用后，下次采用飞速旋转的守夜中，淡紫儿砸地伤害提高 50%。同一件加成最多准备一份，期间可以选择城门连发并保留已准备的加成。背包沿用原道具 ID `patrol_ration`，已有库存与已准备的加成继续生效。

## 靓哥的放纵

商品 ID 为 `liang_indulgence`，商城、背包共用莓紫色胸罩图标。白天任命队长后可在背包使用，同时最多准备一件。下次旋甩守夜中每次砸地半径提升 25%，可与「靓哥的底线」同时生效。准备状态与扣库存一起提交。两件商品分别记录在村庄的 `patrol.rationReady` 与 `patrol.radiusReady` 下，连发夜及其清晨继续保留。使用飞速旋转且队长实际出战时，两项加成随开夜提交移入夜战快照。同夜重进依据快照恢复，结算后失效。旧档缺少此标记时沿用原半径。

## 靓哥的精华

- 白天从背包选择尚未退休的成年村民。确认窗显示这名村民本生剩余次数，取消保留库存。
- 每瓶等概率延后退休 5–20 个成功守夜，最多叠加三瓶。少年成长和老人养老不受影响。
- 完整入档后关闭面板，优先显示目标村民，在身上播放红色上升箭头，然后弹出「靓哥，我好了」。特效使用白天可用的原战技箭头素材。

## 存储与重新开村

| 键 | 数据 |
| --- | --- |
| `daidai_village.backpack` | 独立版本、归属标记、道具 ID 与数量、最后执行的道具操作编号。旧版引导标记只用于迁移 |
| `daidai_village.shop` | 独立版本和归属标记。旧版引导标记只用于迁移 |
| `daidai_village.guides` | 含背包和商城在内的村庄引导记录 |

村庄 A/B 双槽保存粮木、个人剩余劳作期和已使用次数。道具交易在封套记录操作编号及库存改变量，先核对村庄双槽，再将库存和操作编号一并写进背包。重启后可继续未完成的写入，库存按操作编号只更新一次。旧封套无需升级，缺少次数的村民视为未使用。独立存档缺失时从空状态开始。未知版本和无法读取的记录保留原内容，交易停止并提示核对。

重开时先验证首槽新村候选，再删除两份旧存档并回读核对，最后提交另一槽。途中失败保持保存候选，重新进入或重试时继续清理。同一局恢复后仍读取自己的道具和引导。设备设置与云端排行沿原流程处理。
