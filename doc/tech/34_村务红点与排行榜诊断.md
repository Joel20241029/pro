## 红点规则

| 入口 | 亮点条件 | 不亮的情况 |
| --- | --- | --- |
| 村民 | 待安排成年人可填入生产空岗；或有未被照料的孩子且存在可接手成年人 | 岗位已满仅能换人；孩子已有照料者 |
| 家庭 | 存在可成家的男女；或已有家庭满足迎接孩子的全部条件 | 亲属、退休、住房不足、缺粮、冷却、已有未成年孩子、无照料者等阻塞 |
| 建设 | 农田、伐木场、民居、城门任一升级可执行；可扩建民居；或有材料修复受损城门 | 缺材料、费用超出仓储、满房且无其他可建设事项、城门完好 |
| 地图塔位 | 空地可建任一防塔；已建塔可升级 | 材料不足；只有转型可做 |
| 家谱 | 无红点 | 浏览、收藏属于可选操作，不持续提醒 |

只在白天计算。后台、等待继续、口粮确认、保存未完成、资源准备及禁用时收起；普通面板的 CHOICE 暂停不改变判断。打开一次面板不会把红点当成已处理，资源或人员条件变化后由原有 HUD 刷新重新计算。查询不扣资源、不用随机数、不写档。

实现入口：`src/view/ActionHints.ts`。复用 `canMarry`、`birthUnavailableReason`、`upgradeUnavailableReason`、`upgradeCost`、`laborSlots`、`repairCost`；家庭和人口编号同时检查安全整数范围。村民岗位人数统计与命令一致，避免界面假定空岗。

表现入口：`GameHud.ts`、`HudConfig.ts`、`UiGlyphs.ts`。20 逻辑像素矢量红点，按钮右上内缩 8 像素，挂在 `buttonFace` 下，随按钮按压一起移动；不增加图片，不新增可点击区域。塔位红点跟随既有地图锚点，底部建设不会因为只有塔升级而误亮。

## 正式游戏诊断

使用微信主域官方 `wx.getGameLogManager`，标签为 `ranking`。基础库接口说明见 [游戏日志指南](https://developers.weixin.qq.com/minigame/dev/guide/runtime/debug/gamelogmanager.html)。后台路径：基础数据 → 游戏日志分析，协议选择游戏实时日志。筛选版本 `1.0.15`、构建指纹与复现时间，按 `request` 关联一次打开，微信 TraceId 关联该次运行。

| 事件 | 说明 |
| --- | --- |
| open / constructed | 打开请求及 Laya 组件构造完成 |
| viewport | 实际屏幕位置和尺寸 |
| privacy_start / privacy_result | 原有隐私授权请求结果 |
| friend_start / friend_result | 原有朋友信息授权请求结果 |
| message_returned / message_error | 主域 postMessage 返回或抛错；不是开放域处理确认 |
| texture_allocated / texture_updated | 首次分配及首次子图上传返回；不是肉眼可见的证明 |
| texture_error / view_error / runtime_error | 固定错误分类、数值错误码及已知代码文件行列号 |
| authorization_stale / close | 已关闭请求与释放时的累计上传次数 |

版本与构建指纹在 `src/config/ReleaseInfo.ts`。每次打开分配独立请求号，在构造前创建；异步回调保留原请求号。每次启动最多 240 条，同一请求同类异常只记一次，纹理不逐帧打印。无日志 API、日志初始化失败、上报失败时只给本地提示，原游戏继续；纹理异常记录后重新抛出原异常，不吞错、不替换异常。

不上报昵称、头像、openid、好友列表、云成绩、原始错误正文或任意协议对象。只保留固定事件字段，异常调用栈限已知发布文件名及最多 3 个行列号。开放域仍不向主域传递好友数据；原有云成绩读后取最大值策略保持不变。

后续归因顺序：open 缺失检查版本与入口；constructed 缺失查 view_error；权限失败查对应事件；权限成功但未发送 refresh 查生命周期；有 refresh 且有纹理上传返回却仍空白，才结合真机与直接上屏验证继续查合成链。API 调用成功不等于已经在微信后台查到记录。

## 独立直接上屏工程

维护源位于 `project/LayaProject/tools/screen-canvas-probe/`，通过 `prepare.mjs` 输出到 Downloads；不进入正式包。

```bash
node project/LayaProject/tools/screen-canvas-probe/prepare.mjs /Users/happyelements/Downloads/daidai-release-1.0.15/screen-canvas-probe
```

按 [开放数据域官方说明](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/opendata/basic.html) 在任何默认开放域调用前固定 `sharedCanvasMode: screenCanvas`。主域只设置屏幕位置，不读像素、不把原生画布上传成 Laya 纹理。主域 Laya 绘制标题及关闭按钮，原生画布限制在列表范围。隐藏时移出屏幕并将 style 尺寸缩为 1 像素，保留 600×680 画布像素尺寸。

依次验证基础色块、现有微信 Layout 模板、滚动、关闭、重开、位置变化及前后台。列表使用标有“绘制测试”的静态测试行，不调用好友接口，不读取或上传成绩。要决定正式迁移，仍需 iPhone 12 真机和正式环境证据；不能运行中切换两种模式。
