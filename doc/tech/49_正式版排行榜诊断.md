# 正式版排行榜后台排查

## 当前结论

主域面板已显示，但排行榜内容和加载提示全部空白。源码支持的候选原因是：排行榜构造中断、原生共享画布未绑定、上传循环未启动、开放域渲染或正式运行环境的合成受限。尚无正式机日志，不能确认具体原因。

隐私窗口不出现本身不能判定故障。微信官方说明：已经同意时 `requirePrivacyAuthorize` 直接成功；`getPrivacySetting.needAuthorization=false` 还可能表示开发者未声明收集类型，不等于已同意。

## 后台查看方法

1. 登录本游戏 AppID 对应的微信小游戏管理后台。
2. 打开“基础数据 → 游戏日志分析”。
3. 协议选择“游戏实时日志”，先把日期和时间范围缩到复现前后几分钟。
4. 查找日志标签 `ranking`；公共字段 `env` 应为 `release`，并核对 `version`、`codeVersion`、`build`，不要把体验版记录当作正式版记录。
5. 找到 `open`，按同一个 `request` 查看一次打开；也可点击该条的 TraceId“分析”，查看同一游戏启动中的记录。
6. 保存该次打开前后的记录，重点保留 event、category、code、errorName、frames、uploads、canvasWidth/Height、onStage 和公共版本字段。

原日志自 1.0.15 起已接入。如果当前正式版包含该代码，可以先查现有日志；新增细分字段需要本轮诊断代码实际发布到相应环境后才有。

## 日志如何解释

| 最后可见事件/现象 | 下一步检查 |
| --- | --- |
| 没有 `open` | 核对正式版本、复现时间、日志接口是否支持/成功送达、后台筛选，不直接认定游戏没调用 |
| `construct_start` 后 `view_error`，无 `native_view_ready` | 原生 Laya 组件构造失败；看固定异常类型和文件行列 |
| `native_view_ready` 后中断 | 看画布绑定与尺寸设置；`canvasPresent=false` 表示引擎未绑定画布 |
| `canvas_sized` 后中断，无 `texture_ready` | 纹理创建、替换或旧纹理回收阶段 |
| `texture_ready` 但无 `attached` | 组件挂载阶段 |
| `refresh_start` 后出现 `privacy_start` | 已实际进入原隐私申请链 |
| `privacy_snapshot.needAuthorization=true` | 当前微信报告需要隐私授权；同时看 `privacy_result` 的实际结果 |
| `privacy_snapshot.needAuthorization=false` | 不能区分已同意与未声明，结合后台正式隐私配置及实际API结果 |
| `friend_snapshot.friendState` | `granted` 已授权、`denied` 已拒绝、`unset` 未设置；不代表已取得好友数据 |
| `privacy_result` / `friend_result` 为错误级别 | 看权限/声明分类与数值错误码，不按“已同意”继续 |
| `message_returned` 的 message 为 `refresh` | 主域发送返回，不是开放域处理或绘制确认 |
| `render_sample.uploads=0` 或字段缺失 | 检查 canvasPresent、active、visible、onStage、纹理尺寸及运行错误 |
| `texture_error` | 检查 immutable_texture、subimage_upload、canvas_security 等分类及文件行列 |
| 有上传且仍空白 | 上传调用返回不证明画布有内容；继续查开放域与正式环境合成，不能据此宣布已正常 |

`privacy_snapshot`、`friend_snapshot` 是不阻塞原流程的旁路查询。旧窗口结果晚到时仍记录旧 request，不能和新窗口混读。`render_sample` 打开后两秒仅观察一次，不是超时重试。

## 证据边界

- 使用官方 `wx.getGameLogManager`，基础库需要 3.7.4；每次游戏启动最多 240 条，小于官方 999 条限额。
- 不支持或上报失败时沿用现有本地提示，游戏继续；不能保证这类环境的日志出现在后台。
- 日志 success 只说明微信日志接口回调成功；仍应在后台确认实际记录。
- 不回传开放域数据，不记录好友列表、昵称、头像、openid、云成绩、原始错误全文或完整堆栈。
- 体验版验证无法证明正式版已修复。请用同一手机、同一账号比较并记录各自版本和复现时间。
