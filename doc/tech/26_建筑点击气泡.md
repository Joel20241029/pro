# 建筑点击气泡

日期：2026-11-12。配置版本保持 12。本轮只增加建筑名称提示，不修改住宅、资源、人口、升级或存档规则。

后续地图人物点击与屏中 Tip 共享主体已接入，当前点选逻辑和资源统计以 [27 地图村民详情与共享 Tip](27_地图村民详情与共享Tip.md) 为准。下文保留气泡首次接入时的实现范围与验收记录。

## 已确认行为

| 项目 | 实际实现 |
| --- | --- |
| 点击入口 | 左侧民房 `building:house-a` 显示“佟楼”，右侧 `building:house-b` 显示“南楼” |
| 外观 | 原创浅米黄底板、暖棕像素边和深棕文字，下方带短指角，没有按钮 |
| 展开 | 以指角尖端为原点，从零放大至完整尺寸，耗时 0.16 秒，减速到位 |
| 收起 | 同一尖端为原点缩回零，耗时 0.28 秒，加速收起 |
| 时长 | 包含展开和收起，总计 2 秒；不受战斗倍速影响 |
| 再次点击 | 同一民房重新计时；另一民房立即替换楼名及挂点，同时只显示一条 |
| 生命周期 | 打开主动或自动面板、切换村庄、销毁界面时立即收起并清除目标 |
| 前后台 | 后台或应用禁用时不推进提示时钟，沿用现有屏中 Tip 的视觉时钟策略 |

用户在确认接入后明确改为“从箭头指向的点放大出来，消失时缩回去”，因此最终采用尖端缩放，不沿用最初草案的透明度淡入淡出。

## 代码职责

- `project/LayaProject/src/view/AnchoredTip.ts`：可复用的文字气泡组件。接收文字和目标范围提供函数，负责绘制、坐标转换、缩放和两秒生命周期；不读取业务状态，不创建独立 Timer 或 Tween。
- `view/config/AnchoredTipConfig.ts`：气泡尺寸、指角、间距、动画时间及两个民房显示名。总时长复用 `UI.tipSeconds`，其他表现参数限制在此配置内。
- `BuildingVisuals.bodyRegion()`：提供当前建筑主体的实际局部可见范围。切换外观时清除缓存，坐标换算始终读取当前 Body 变换。
- `VillageWorld`：只为两栋民房配置点击范围和现有 `UiWidgets.bindClick`。两个民房点击范围交叠时，按既有足底排序选择前景民房。
- `GameView`：只在白天、守夜且没有面板时显示；使用实际 `overlay.numChildren` 收起提示，覆盖每日口粮等不经过主动面板入口的流程；负责视觉时钟、窗口重排、新村清理和销毁。

`UiWidgets.bindClick` 现在将原始点击事件透传给回调，用于交叠民房选择；现有无参数回调仍可使用，按钮按压、拖动取消和点击音效保留。

## 坐标、遮挡与缩放

建筑编辑器中现有 `VisualBounds` 含安全留白，不是精确屋顶。因此挂点采用 `Body.getSelfBounds(rect, true)` 的顶部中心，包含各裁边贴图的真实绘制范围，再由 `localToGlobal` 转到气泡父层。Body 外观变化时重建范围缓存；升级动画只改变当前变换，不缓存屏幕坐标。

主体尺寸为 `120×64`，指角 `20×14`，重叠 `6`，组件总高 `72`；pivot 固定为 `(60,72)`，即指角尖端。目标位置位于真实屋顶中心向上 `8` 个设计像素。整个气泡按此点缩放，因此展开、停留和收起时尖端不漂移。正文为 `28` 号、双向居中，颜色复用 `C.tipInk`。

气泡显示层高于场景和 HUD、低于面板；组件、文字及指角均不接收输入。使用实际 Body 矩形作为民房点击范围，交叠民房用 `compareDepth` 选择。没有增加全场景逐像素点击遮挡系统，也没有改变现有村民、树木的输入行为。
