## 2. 界面维护入口

下表路径相对于 project/LayaProject/src/。

| 文件 | 职责 |
| --- | --- |
| view/GameView.ts | 唯一 game.changed 订阅；根节点、通知、刷新、换屏和销毁 |

| view/ViewText.ts | 姓名转义和颜色、数值缩写、费用及升级增量格式 |
| view/GameHud.ts | 资源、日期、塔说明、血条、警钟和底部操作；战斗帧只更新现有节点 |

| view/GamePanels.ts | 唯一当前面板；open/close/send/modal、分发和 CHOICE 暂停 |
| view/panels/PanelContext.ts | 分类面板可访问的明确服务，不暴露整个 GameView |
| view/panels/PeoplePanels.ts | 村民/家谱、人选列表、调岗、照料、驻塔和详情 |
| view/panels/FamilyPanel.ts | 家庭卡片、成家和迎接孩子入口 |
| view/panels/BuildingPanels.ts | 建设、塔位升级、来敌和开始守夜 |
| view/panels/JournalPanels.ts | 小记、说明、好友榜、传承与纯净重开 |
| view/panels/SessionPanels.ts | 启动/异版/保存待确认、口粮、返回、清晨和失败 |
| view/VillageScene.ts | 场景映射、占地、深度比较和导航算法 |

保留的关键约定：

- 文字字号下限仍取决于父节点名称；不增加会改变判断的包装 Sprite。
- 按钮第 0 子节点仍是 buttonFace；文字和图标一起按压，外层点击区域固定。
- ScrollList 回调写回同一个 Panel.scroll，不复制面板状态。
- send(command, false) 先清面板、解除 CHOICE，再执行可能同步刷新的命令。
- refresh(true) 保留原面板、滚动节点和排行榜实例；换屏只定位和更新开放域触摸范围。
- Tip/升级动画、村民和战斗 tick 保留不同的暂停条件。
- 各模块不重复订阅会话；销毁仍先撤销 changed，再销毁唯一 root。

## 4. 参数修改位置

| 参数 | 文件 | 调整影响 |

| 资源/成长、人口/精英、寿命、经济和村规 | config/RuleConfig.ts | 影响经济和保存重演；ECONOMY 来自原计算函数字面量 |

| 安全区、地图比例、人物显示比例、HUD 图文/标签/血条 | view/config/HudConfig.ts | 只影响表现，须复查短屏和长屏，不改射程 |
| 森林/建筑布点、尺寸、占地、工位、篝火站点、行走和婚礼 | view/config/VillageSceneConfig.ts | 尺寸、底座与工位需配套验证 |

GameConfig.ts 直接导出原对象，没有复制数组或重建对象，对外运行时导出仍为原 18 项。新内部参数从所属配置文件引用。注释标明原值来源、范围和影响，此次没有调参。

面板专用的一次性排版坐标保留在所属面板；共用控件和可调 HUD 参数集中管理，不把数组下标及数学运算机械拆成配置。
