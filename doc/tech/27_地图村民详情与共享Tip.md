# 地图村民详情与共享 Tip 底板

日期：2026-11-12。已按用户确认的方案接入地图点击入口，并处理追加的屏中提示样式要求。配置版本保持 12，不修改生产、成长、家庭、战斗和存档规则。

## 玩家操作

- 点击地图上当前显示的村民，直接打开名册原有的个人详情。成人、孩子、婴儿、老人和精英共用该入口。
- 详情仍按原规则展示天赋、专长、当前岗位、成长或剩余寿命、双亲与精英信息；可执行的工作调整保持昼夜和年龄限制。
- 打开详情沿用 `GamePanels.open` 的 `CHOICE` 暂停，关闭沿用 `close` 恢复。其他暂停原因不会因此被移除。
- 多人重叠时点选前景人物；前景民房仍显示楼名气泡，其他前景树木或建筑阻止穿透选中后面的人。农田地面不挡点击，独立水车仍参与遮挡。
- 进入塔内后隐藏的驻守者不接受地图点击，仍可通过原名册或塔面板查看。人物移动、节点换人或隐藏后，失效的旧按下事件不会打开另一人资料。

## 详情排版更新

2026-11-12 根据玩家反馈，将个人及先辈详情改为纵向居中：姓名标题保留原中轴，头像移到面板中央，岗位/成长/寿命说明位于头像下方，双亲或来历居中显示。普通头像仍为 112，精英仍为 140，尺寸与业务信息均不变。

精英的加成说明、调岗及照料按钮相应下移，保留文字和边框间距；精英老人和先辈共用该排版，说明或珍藏按钮避开加成区域。面板仍为 `668×860`，保留原安全区居中和长短屏适配，不增大底板，也不增加图片资源。改动仅在 `PeoplePanels.ts` 的显示坐标、尺寸和对齐参数。

## 入口与身份保护

`VillageWorld` 继续维护原人物精灵池和 `compareDepth` 绘制顺序，将最终深度列表保存用于点按。`pickAt` 在事件发生时逆序查找，绕开 Laya 3.4.2 原生输入只按子节点插入顺序遍历的问题；不调整渲染树或增加全场景点击框架。

人物命中范围由当前自身贴图 `getGraphicBounds` 提供，不包含头顶红心；坐标通过 `globalToLocal` 处理人物镜像、精英缩放和父层变换。建筑、树木及水车使用自身可见部件的合并矩形范围。该方案为矩形近似遮挡，不是逐像素透明度检测。

按下时按 `touchId` 记录原生命中源节点及其身份、最终前景目标的 ID 与节点；点击时重新拾取并比对。移出、离开显示树、重新开村、节点换人或隐藏时清理相关记录，并使用已有 `Laya.InputManager.cancelClick` 取消旧点按。每帧先填充整个人物池，最后才检查身份和可见性，避免临时批量隐藏造成误取消。

`GameView` 检查当前人物仍存在、阶段为白天或守夜、实际 `overlay` 没有面板后，调用原有 `GamePanels.open({ type: "person", id })`。每日口粮等自动面板也会阻挡地图输入。个人详情内容未复制到新的面板类，面板打开后民房气泡沿既有流程收起。

## 屏中 Tip 样式

`Tip.ts` 改用已有 `panel_anchored_tip` 主体九宫格，保持屏幕安全区居中，不使用建筑气泡指角。正文改用 `C.timber`（`#9a591f`）棕橙色，保留 30 号字体、浅色细描边、居中排版和长文案自适应高度。

两秒总时长、淡入淡出、文本安全区及点击穿透保持原规则。建筑气泡继续使用 `C.tipInk` 和尖端缩放，两类提示共用底图、各自管理原有动画。

没有新增图片。`res/source/asset_recipe.json` 将旧 `panel_tip` 标为非运行素材，并将 `panel_anchored_tip` 标注为两个组件共用；旧母版继续保留。原图与制作说明见 [共享底板制作源](../../res/source/ui/anchored-tip/README.md)。重建后仍为 229 张源画布，其中运行 198 张、备用 31 张、2 页图集；资源白名单为 1,824,832 字节，比上一版减少 2,093 字节。
