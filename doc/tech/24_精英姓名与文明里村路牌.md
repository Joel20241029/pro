# 精英姓名与文明里村路牌

日期：2026-11-12。用户确认只调整精英姓名，普通姓名规则保留；村门左侧新增“文明里村”路牌。

## 1. 精英姓名

新生儿和旅人已经判定为精英后，使用男女共用的11名池：旭勇、智卓、二百、翟毅、周博、赵靓、龙龙、昭易、明波、宋磊、徐超。精英不再使用“芊芊”，这些专用名不加孩子编号。普通人的孩子字根、旅人姓名、四辈儿（男）和芊芊（女）均保留。

配置位于 `GameConfig.VILLAGER_NAMES.elite`。出生和旅人入口在命名前保存随机状态，主随机流仍消费原来的普通姓名抽样和精英判定；精英姓名使用该状态的独立 `SeededRandom` 实例。这样只替换姓名，不移动后续随机流、不改变5%精英概率、性别平衡、天赋或专长。允许按现有规则重名，不引入重抽或去重。已有村民不批量改名，不改变存档结构或迁移旧档。

审核确认上述随机流方案可行。修改前后各运行4096次出生和4096次旅人生成，对完整游戏状态只屏蔽精英的name字段后计算哈希，结果完全一致；出生精英208个、旅人精英198个，两轮数量一致。普通人的姓名也包含在比较中。新增测试验证两种来源的男女精英均能覆盖全部11名，并确认普通女性仍能抽到芊芊、男性仍能抽到四辈儿。

## 2. 路牌设计与接入

采用浅蜜色木牌、深棕描边、短木桩和小石脚，牌面中央保留干净区域；文字以22设计像素、深棕色、浅色细描边单行居中，避开铆钉。文字由Laya渲染，独立于底图，缩放后保持清晰。

| 项目 | 参数与用途 |
| --- | --- |
| 场景ID | `deco:village-sign`，不进入建筑升级逻辑 |
| 参考足底 | x178、y832，沿用场景自适应纵坐标映射 |
| 显示宽度 | 140设计像素，高度保持源图比例 |
| 源画布 | 88×52，pivot(44,50)，最终图集仅裁透明边缘 |
| 文字框 | 相对显示宽度：x10%、y13.75%、宽80%、高20% |
| 遮挡 | 文字是路牌子节点，牌体作为整体按足底排序 |
| 通行 | 桩脚位于已有左城墙安全边，不新增障碍，保留两侧入村通道 |

审核后将初始x190左移到178，给左火把留开空间。路牌比城墙足底低2设计像素，桩脚落在既有导航安全边中；与城门血条、城门主体分离。源底图经过已有图集排布模拟后选用88×52，画面仍显示140宽，单独的中文不受底图分辨率影响。最终仍为2页图集，没有为路牌增加一整页纹理。

- 母版与完整提示词：`res/source/decorations/village_sign.png`、`village_sign.prompt.txt`，由内置image_gen生成，保留透明背景。
