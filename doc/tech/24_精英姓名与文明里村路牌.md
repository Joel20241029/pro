# 精英姓名与文明里村路牌

日期：2026-11-12。最新确认：四辈儿加入男女共用的精英姓名池，普通姓名中删除四辈儿和芊芊；村门左侧保留“文明里村”路牌。

## 1. 精英姓名

新生儿和旅人已经判定为精英后，使用男女共用的 12 名池：旭勇、智卓、二百、翟毅、周博、赵靓、龙龙、昭易、明波、宋磊、徐超、四辈儿。这些专用名不加孩子编号，精英和普通人都不再生成“芊芊”。普通孩子只用“小＋禾/桃/松/竹/杏/川＋编号”，普通旅人只用行舟、云溪、山青、晚晴。

配置位于 `GameConfig.VILLAGER_NAMES.elite`，原 `personal` 配置及出生、旅人的对应分支已移除。普通姓名抽样范围直接使用现有名单长度，不保留旧姓名占位。主随机流仍按普通姓名、精英判定的顺序抽样；精英姓名继续使用命名前快照的独立 `SeededRandom` 实例。精英概率仍为 5%，性别、天赋、专长和能力规则不变。允许按现有规则重名，不引入重抽或去重。已有村民不批量改名，不改变存档结构或迁移旧档。

姓名测试通过真实出生和来访入口各生成 4096 人，检查男女精英分别覆盖全部 12 名，且普通人不会抽到任何精英专属名或芊芊；同时验证普通孩子格式、旅人名单和人口数量。旧的按性别专属姓名测试已删除，相关人口与姓名检查集中到 `elite-names.test.cjs`。原路牌交付的 `naming-comparison.json` 是旧 11 名方案的历史证据，不代表当前姓名规则；普通名单长度变更后，不再声明所有种子下的随机流与旧方案逐字段一致。

## 2. 路牌设计与接入

采用浅蜜色木牌、深棕描边、短木桩和小石脚，牌面中央保留干净区域；文字以22设计像素、深棕色、浅色细描边单行居中，避开铆钉。文字由Laya渲染，独立于底图，缩放后保持清晰。

| 项目 | 参数与用途 |
| --- | --- |
| 场景ID | `deco:village-sign`，不进入建筑升级逻辑 |
| 参考足底 | x178、y832，沿用场景自适应纵坐标映射 |
| 显示宽度 | 140设计像素，高度保持源图比例 |
| 源画布 | 88×52，pivot(44,50)，最终图集仅裁透明边缘 |
| 文字框 | 相对显示宽度：x10%、y13.75%、宽80%、高20% |
| 遮挡 | 文字是路牌子节点，牌体作为整体按足底排序 |
| 通行 | 桩脚位于已有左城墙安全边，不新增障碍，保留两侧入村通道 |

审核后将初始x190左移到178，给左火把留开空间。路牌比城墙足底低2设计像素，桩脚落在既有导航安全边中；与城门血条、城门主体分离。源底图经过已有图集排布模拟后选用88×52，画面仍显示140宽，单独的中文不受底图分辨率影响。最终仍为2页图集，没有为路牌增加一整页纹理。
