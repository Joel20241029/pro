# 百毅靓之怒：全塔伤害强化设计

日期：2026-11-14。状态：已实施、完成源码与微信 IDE 验证，微信平台已确认 1.0.20 上传成功并覆盖当前体验版。

## 1. 用户要求与方案选择

用户最新明确名称为“百毅靓之怒”，效果改为全塔伤害提高 50%，与大王之心呼应。原“全场削血、减速、红金道路冲击波”方案及带“力”的旧名称均被替代。

本次采用每座驻塔的局部强化表现：发动闪光、持续蓄力光、强化弹道与命中反馈。道路冲击波容易表达为直接对全场敌人造成伤害，与本轮机制不符，所以保留旧稿作历史记录，采用新的局部强化稿。

用户已确认 15 战斗秒及局部红金光表现。学习条件为当前村庄成功守住 3 波、一次消耗 40 木和 20 粮；学习后切换与施放免费。每夜一次、单槽携带、白天更换复用已实施的战技系统。

## 2. 效果规则

| 项目 | 设计 |
| --- | --- |
| 作用对象 | 所有已建成且有村民驻守的防塔 |
| 核心效果 | 技能生效时发起的攻击，伤害倍率额外乘 1.5 |
| 持续时间 | 15 个战斗秒；暂停停止计时，3 倍速约持续 5 个现实秒 |
| 次数与携带 | 每夜一次、释放免费；战前与大王之心二选一 |
| 箭塔 | 主目标伤害提高 50% |
| 石塔 | 本次范围攻击中所有实际受伤对象的伤害提高 50% |
| 寒塔 | 主目标伤害提高 50%，范围减速强度与持续时间保持原规则；不给范围内其他目标新增伤害 |
| 护甲 | 沿用原减伤；石塔仍使用原有护甲计算，没有新增穿透 |

倍率纳入已有等级、天赋、专长、政策与精英伤害计算，在最终取整之前应用。整数取整和最低 1 点伤害保留，个别最终整数不会严格等于旧整数乘 1.5。

在不浪费伤害、持续有目标的理想条件下，攻速乘 1.5 和伤害乘 1.5 的理论输出收益相近。实际区别取决于攻击时点、溢出伤害及寒塔减速覆盖等，不能宣传为天然更强的破甲技能或 Boss 克制技能。

建议玩家短说明：

> 全部驻塔伤害提高 50%，持续 15 个战斗秒。每夜可用一次。

## 3. 视觉设计

![全塔伤害强化效果](../../res/design/tactics/03_百毅靓之怒_全塔伤害强化.png)

这是概念合成图，场景用于交代技能效果，不作为修改当前塔位、建筑布局或塔大小的要求。

### 3.1 发动

- 按钮采用赤金攻击意象，名称完整显示五个字“百毅靓之怒”，与图标共同按压；正式图标需单独制作。
- 已建驻塔的武器挂点各出现一次短促红金亮闪，计划约 0.2 个战斗秒，目标是让玩家迅速识别全部塔已强化。
- 闪光围绕武器挂点，跟随塔外观缩放和深度层级，不扩张建筑占地或点击区域。

### 3.2 持续

- 塔顶保留低强度红金呼吸光，可配细窄的基座光环；主体木纹、弓弩、投石装置和冰晶仍清晰可见。
- 箭仍为箭形，石弹仍保留石头材质，寒弹及寒塔晶体保持青蓝色；只增加暖色亮边或短促出膛闪，不增大原弹道尺寸。
- 不加入粒子系统、长拖尾、持续喷火或整条道路覆盖。用少量二维贴图及缩放、透明度和颜色动画表达。
- 主按钮沿用剩余秒数与环形倒计时，强化结束后塔身光效淡出，本夜按钮显示已用。

### 3.3 命中

- 强化攻击视觉到达目标时出现一个短促红金小闪，并沿用现有敌人受击红闪。
- 石塔在主落点显示一次小闪，其余实际受伤对象沿用红闪，避免群怪每人叠加一团大光效。
- 特效不遮盖 HUD、血条或敌人脸部，死亡对象继续遵循现有死亡快照与视觉到达时序。

## 4. 审核结论与接入边界

已核对当前 `main` / `46362ff5dbd948881b796981e102153600c4e343` 下包含既有未提交修改的源码；只读审核确认方案可行。此结论是源码设计审核，不是已完成运行验证。

| 已有实现 | 可复用边界 / 待实现部分 |
| --- | --- |
| `TacticConfig.ts` | 当前只允许 `ATTACK_SPEED`，新增伤害效果需要扩展效果分支和校验，不能仅追加配置 |
| `BattleSimulation.ts` | 三塔统一伤害路径可接 1.5 倍；攻速倍率必须只作用于大王之心，寒塔减速路径独立保留 |
| `NightControls.ts` | 名称、图标、总时长、倒计时和使用状态已读取当前战技；新的五字标题需实绘校验 |
| `CombatPresentation.ts` | 可复用视觉到达时红闪及死亡快照；红金小闪需新增正式表现，不能当成当前已有完整效果 |
| `VillageWorld.ts` | 可复用固定弹道节点池及战斗时间驱动；现有统一光圈不等于已经具备武器局部光效 |

关键时序：当前伤害在发射当步结算，弹道只是后到的画面。正式实现需要把本次攻击是否获得强化固化在 `Shot` 或反馈事件中；结束前发出的强化弹道保留强化命中反馈，开始前发出的普通弹道不在半空变成强化。不能在视觉命中时重新读取技能倒计时或重复扣血。

动态调任驻守、打开面板、暂停和倍速都不能重置已用次数或剩余时间。持有增强状态但无驻守的空塔不发射，也不额外产生伤害。

- `TacticConfig` 登记伤害型战技，学习校验/原子扣费/携带/继承复用现有系统。存档结构保持版本15，1.0.19既有进度可直接通过同一校验，不增加迁移或缺字段兜底。
