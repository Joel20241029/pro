## 规则与证据边界

玩法语义以 [游戏设计](../design/01_游戏设计.md) 为基础。用户本轮已授权开始制作，只做微信小游戏；实际首版配置、已完成范围和未完成项以 04 的记录为准。原型参数仍需要真实试玩调整。

本轮最终确认成人男女各一种外观，补齐男女耕作、伐木、照料动作；劳作期内男女均可承担各岗位。取消主动待命按钮，采用专长优先自动填空岗，允许满岗直接换人。普通劳作期结束后留村养老三夜（精英五夜），仍吃粮并占住房；寿终后才入家谱。全部九类分页列表改为滑动，关闭按钮保留右侧。历史存档兼容已删除，开发交付后人工清档，正常重启保留同版本进度，详见 08。本轮进一步统一六类人物的冷暖配色与发型辨识；家庭条目提前显示生育阻塞原因并禁选，详见 09。当前全部 32 组动画有运行入口，静态候选素材仍不等于全部接入。

两张运行图集已在微信发布包中加载显示，完整目录已计量。开发者工具验证不等于真机验收，原始目录字节不等于平台上传体积。
