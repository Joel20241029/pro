## 规则与证据边界

玩法语义仍以 [游戏设计](../design/01_游戏设计.md) 为准；本技术稿把它转成明确实现合同，没有把原稿待确认的玩法假设变成已经批准的业务。具体新增原型参数及待核实事项集中在 01 的最后一节。

本轮新增的确定要求是序列帧动画。为此，原先建议的身体/发型部件组合调整为有限整人动作映射；这是美术表示的细化，不改变天赋、性别、岗位或亲缘规则。每个角色实际具备的动作都列在 02 中，没有用文件数量声称完整全动作库已完成。

候选资源图集通过本地文件检查，不等于已经在 Laya 中显示正常；素材字节达标不等于完整小游戏底包达标。先执行 T00 的真实单包样本，再实施与验证玩法。
