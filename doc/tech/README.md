## 规则与证据边界

玩法语义以 [游戏设计](../design/01_游戏设计.md) 为基础。用户本轮已授权开始制作，只做微信小游戏；实际首版配置、已完成范围和未完成项以 04 的记录为准。原型参数仍需要真实试玩调整。

本轮新增的确定要求是序列帧动画。为此，原先建议的身体/发型部件组合调整为有限整人动作映射；这是美术表示的细化，不改变天赋、性别、岗位或亲缘规则。每个角色实际具备的动作都列在 02 中，没有用文件数量声称完整全动作库已完成。

两张运行图集已在微信发布包中加载显示，完整目录已计量。开发者工具验证不等于真机验收，原始目录字节不等于平台上传体积。
