## 规则与证据边界

玩法语义以 [游戏设计](../design/01_游戏设计.md) 和各轮已确认规则为基础；当前恢复方案见 31。成人男女、男孩女孩、男女老人和婴儿按既有二维素材映射；不沿用试验中的中性儿童、老人模型划分，不修改人物性别、姓名、生育、岗位或寿命规则。

自动岗位、换人、养老、每日口粮、纯净开村、最高纪录、暂停恢复和资源重试均应分别验证。历史测试通过次数及旧二维实绘不能替代当前入口回归；测试桩中的帧、布局与粒子契约检查也不能替代实际引擎的动作、遮挡、射口和操作验证。开发者工具验证不等于真机验收，目录原始字节不等于平台上传体积。
