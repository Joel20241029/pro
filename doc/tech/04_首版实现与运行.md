# 代代守村：首版实现与运行

2026-11-11 更新：单局最高成功防守波数好友榜、5% 精英村民及放大成家红心已实现。普通寿命 12/3 夜，精英 18/5 夜，配置版本 4；实现、资源源文件和验证边界见 [10 好友榜与精英村民](10_好友榜与精英村民.md)。下文历史测试及包体数字保留对应轮次含义。

日期：2026-11-10。目标工程：[LayaProject](../../project/LayaProject/)。本轮为可以操作的微信单机首版；不是上线验收完成声明。

## 1. 本轮确定的范围

用户已明确开始实现，只做微信小游戏，不考虑其他平台兼容；AppID 为 `wx46e59dc5dc95b52f`。原有设计和技术合同继续作为首版规则依据。旧文档中的 `PlatformBridge` 在实际代码中收敛为 `WechatPlatform`，直接使用微信存储、窗口信息与前后台接口，没有浏览器存档替代实现。

实施前由独立子 Agent 审核可行性：先核实真实微信单包成本，再实现经营、战斗、保存和清晨队列，最后在微信开发者工具运行。实际导出基础内容约 2.31 MB 后开始业务实现；最终文件字节以本轮包体报告为准。

## 2. 已实现的可玩流程

| 环节 | 实际行为 |
| --- | --- |
| 开村 | 固定六名村民、两间民居、一个家庭；箭楼与石塔各一座且已驻人 |
| 经营 | 耕作、伐木、照料；空闲成人按专长优先自动填空岗，支持满岗换人；民居建设、生产建筑升级、城门修复 |
| 村民活动 | 按岗位自主往返、工作与休息；绕开建筑底座；人物和建筑按足底位置形成前后遮挡 |
| 家庭 | 成年单身双方成家；检查直系与共同父母；花费 20 粮生育并指定照料人 |
| 成长 | 照料并守住两夜后成年，继承双亲之一的天赋，选择三项候选专长之一 |
| 接班 | 新成人有完整 12 夜劳作期，选完专长自动填生产空岗，驻塔手动安排；荣休释放岗位并留村养老 3 夜，仍吃粮、占住房；寿终后释放人口和家庭 |
| 守夜 | 四个塔位、三种塔、升级与转型；五类敌人、固定路径、范围伤害与减速 |
| 操作 | 暂停、两倍速、每夜一次警钟；暂停时可以调任驻塔者 |
| 长期变化 | 四季、十二项村规、旅人、每年挑战档、预算有界的随机波次 |
| 失败重开 | 显示本局守夜、出生、退休和代数，保留累计记录与有限家谱、收藏；可传承一项发现过的天赋 |
| 保存 | 只读当前版本；双槽校验、精确候选读回、失败冻结重试；开发交付时人工清档，正常重启保留进度 |
| 重进 | 白天继续经营；夜间从已保存的战前状态重打；清晨继续未完成选择；失败恢复失败页 |
| 名字与列表 | 四辈儿仅入男名池、芊芊仅入女名池，不增人口；九类列表上下滑动，关闭按钮在右侧，移除麦穗与地图独立“家园”字样 |

固定开局、经济与战斗数值集中在 [GameConfig.ts](../../project/LayaProject/src/game/GameConfig.ts)。具体规则仍以代码与自动回归的共同结果为准，不把文档里全部后续验收项视为已经测试。

## 3. 工程接入

- [Main.ts](../../project/LayaProject/src/Main.ts)：唯一启动与帧循环，装配微信平台、资源、会话和界面。
- [Scene.ls](../../project/LayaProject/assets/Scene.ls)：挂载原有 Main 脚本 UUID。序列化格式经过安装版发布器输出验证，生成包实际启动成功。
- [GameSession.ts](../../project/LayaProject/src/game/GameSession.ts)：经营命令、候选保存、战斗结果提交与暂停原因集合。
- [VillageRules.ts](../../project/LayaProject/src/game/VillageRules.ts)：经济、家庭、成年、退休、清晨选择及家谱保留。
- [BattleSimulation.ts](../../project/LayaProject/src/game/BattleSimulation.ts)：每秒 20 步，先处理到门伤害再攻击；画面和投射物不结算伤害。
- [SaveStore.ts](../../project/LayaProject/src/storage/SaveStore.ts) 与 [StateValidation.ts](../../project/LayaProject/src/storage/StateValidation.ts)：CRC32、规范化 JSON、双槽重试及引用不变量。
- [WechatPlatform.ts](../../project/LayaProject/src/platform/WechatPlatform.ts)：直接封装 `wx.getStorageInfoSync`、`wx.getStorageSync`、`wx.setStorageSync`、`wx.getWindowInfo`、前后台事件。
- [GameView.ts](../../project/LayaProject/src/view/GameView.ts)：村落画面与全部首版面板；[SpriteFrames.ts](../../project/LayaProject/src/view/SpriteFrames.ts) 负责共享纹理与帧选择。
- [VillageScene.ts](../../project/LayaProject/src/view/VillageScene.ts) 与 [VillagerMotion.ts](../../project/LayaProject/src/view/VillagerMotion.ts)：固定占地与可达站点、足底排序、按人物身份保存的纯表现行走行为，详见 [05](05_村民自主行为与遮挡.md)。
- [ScrollList.ts](../../project/LayaProject/src/view/ScrollList.ts)：核心 Sprite 裁剪容器，九类列表复用，拖动取消点选、同一手指跟踪及销毁解绑，详见 [08](08_晚年生活与滑动列表.md)。
- [ProjectileMotion.ts](../../project/LayaProject/src/view/ProjectileMotion.ts)：读取已结算攻击，播放箭矢、抛石、冰球和短促命中；跟随战斗 tick、复用 32 个显示节点，详见 [06](06_视觉升级与资源管线.md)。

画面逻辑坐标为 720 × 1280。微信画布采用固定宽度适配，游戏区在安全区内显式居中；右上角微信胶囊位置不放游戏设置按钮。关闭 3D 与 UI 模块，界面由核心 Sprite、Text 与 Graphics 实现。
