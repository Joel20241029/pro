## 已确认要求与设计建议

用户已经明确的要求：

- 微信小游戏，竖屏，轻量。
- 村落经营、人类村民成家繁衍、塔防结合。
- 单机游戏。
- 完整游戏不能超过小游戏底包大小。
- 能够持续游玩，没有固定的预制关卡终点。
- 人物采用序列帧动画，每个动作 2～4 帧；本轮候选资源按每动作 4 帧准备。

本文采用严格的单包解释：核心运行所需的引擎、适配、代码、图片、音频和配置都在同一个发布包中，不借助分包、远程资源或共享引擎插件绕过限制。若需要改变这一解释，必须另行确认。

除此之外，具体数值、退休规则、旅人机制、血缘限制、失败传承、存档恢复等均为本稿提出的建议；用户尚未逐项确认。它们被写成明确规则是为了让方案可评审，不代表已经实施或获得上线认可。
